# Model checkpoints

Trained `.pt` files are not tracked because the local collection is several gigabytes and contains files above ordinary GitHub hosting limits. Generate weights with `src/train.py` after preparing authorized local datasets, or obtain a verified artifact bundle from the project owner.

The default web authentication scanner gate needs `transformer/efficientformer_l1_rgb_best.pt` and Dataset 1 validation images. CNN one-vs-all authentication paths need per-scanner checkpoints and the frozen thresholds in `results/tables/binary_threshold_calibration.csv`.
