Authentication system · live inference lab

Four gates to
a single key

Register with a password (bcrypt), a passkey (TOTP), an enrolled fingerprint, and a bound scanner. Sign in re-checks every factor — the gate trace shows each one live — and the scanner gate is model-dependent: EfficientFormer-L1 RGB runs the official 448-D cosine verification, while the CNN models run the one-vs-all binary gate. A real HMAC-SHA256 mutual exchange then folds all four factors into one session key. Below the account panels, drop any probe on the deck to run the checkpoints directly: identify the scanner, verify a claim, or replay the mutual handshake.

Before you log in

use a Dataset 2 sample whose scanner matches the bound one

Enrollment stores only the derived template vector (no raw fingerprints, no pickle). The one-time passkey base32 secret appears exactly once, in the confirmation overlay right after registering. Sign in runs all four gates — stored password, TOTP code, fingerprint template, scanner verification (model-dependent, via the Model you select: EfficientFormer-L1 RGB 448-D cosine or CNN one-vs-all binary sigmoid) — then the HMAC exchange derives the shared session key, all shown live in the gate trace. The lab below runs the same checkpoints directly on any probe; the first model load takes ~30–60 s on cold start.
