D

Scanner verification — official final method

separate from identification · does not compete in the tables above

Verification answers a different question than identification: it checks whether an image is genuine for a claimed scanner. The official verification method is the EfficientFormer-L1 RGB 448-D normalized-embedding cosine protocol described above. Older one-vs-all binary verification runs are separate CNN gate experiments; they are not the official final verification result.

F

Dataset evaluation

what each split measures

Dataset 1 — training & validation

  • 2,019 raw fingerprints, folder = scanner class (Sensor 1–10).
  • 70/30 per-scanner stratified split (1,413 train / 606 val).
  • 10-class scanner identification and one-vs-all verification models are trained here.
  • Threshold calibration happens on the validation split only.

Dataset 2 — independent test

  • 200 fingerprints from users A & B — unseen users.
  • Files named Sensor<n>(Test<m>)<k>.bmp — (Test1) = User A, (Test2) = User B. The scanner hardware is known and taken from the same R307 unit family.
  • Never used for training, validation, or threshold selection — test only.

Dataset 2 is an unseen-user evaluation on known scanner hardware. It does not test generalization to unseen hardware.

G

Interpretation

exactly as measured
  • Identification — "which scanner captured this image?" — is the 10-class classification compared in sections B and C. EfficientFormer-L1 RGB is the best Transformer/hybrid at 88.00% Dataset 2 test accuracy.
  • Verification — "is this image genuine for the claimed scanner?" — is the EfficientFormer-L1 RGB fused 448-D cosine protocol (section D), with EER 2.53% on validation and a frozen threshold of 0.3892.
  • CNN baselines and Transformer/hybrid models are never mixed in a single table — each family is compared within its own section.
  • FAR and FRR are the security-relevant metrics; AUC is useful for comparing discrimination.
  • Results vary by scanner (some sensors verify near-perfectly, others show high FRR / near-chance AUC), so per-scanner thresholds are mandatory.
  • All figures above are reported exactly as measured; nothing estimated or extrapolated.
